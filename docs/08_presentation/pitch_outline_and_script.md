### ⭐ "테스트 통과가 뭘 보장하나요?" — 오늘 생긴 최고의 재료 (사고 I-09)

**질문받으면 이걸 답한다. 회고 섹션에서 먼저 꺼내도 좋다.**

> "저희 E2E 출력에 `PASS`인데 값에 `FAIL` 문자열이 찍히는 줄이 하나 있었습니다. API 담당이 **'원인 못 찾음'이라고 정직하게 남겨** 뒀고, 그 한 줄을 추적했습니다.
> 원인은 검증 스크립트가 **여러 줄 명령치환을 `chk` 인자로 직접 넘긴** 것이었습니다. 파이썬 출력에 공백이 있으면 단어 분리가 일어나 **`chk`가 인자 3개가 아니라 6개를 받고**, 엉뚱한 조각끼리 비교하게 됩니다. 계측해서 `argc=6`을 실측했습니다.
> **위험한 건 값에 공백이 생기는 게 주로 실패 경로라는 점입니다. 검사가 실패해야 할 때 조용히 통과할 수 있었습니다.** 같은 패턴 10곳을 전부 변수 대입 방식으로 고쳤고, 그 뒤 72건 통과입니다.
> **여기서 배운 게 이겁니다 — 통과 개수는 검사가 실제로 비교하고 있다는 증거가 아닙니다. 검증 도구 자체를 검증해야 합니다.** 그리고 이걸 잡을 수 있었던 건 담당이 모르는 걸 모른다고 남겨 뒀기 때문입니다."

**왜 강한가**: 심사자가 듣는 대부분의 발표는 "테스트 다 통과했습니다"에서 끝난다. **테스트를 의심해 본 팀은 거의 없다.** 숫자 자랑이 아니라 방법론 이야기라 Tech Talk 성격에 정확히 맞는다.

출력은 `agent_results.payload_json`에 들어가는데, **에이전트마다 구조가 다릅니다. A1과 A2는 항목형(`items[]`), A3는 문서형(`documents[]`)입니다.** 그래서 이 컬럼만 jsonb고, **조회 조건이 되는 값 — `agent_code`, `edited`, `status` — 은 전부 컬럼으로 뺐습니다.** 구조가 바뀔 수 있는 것만 JSON, 조회 조건이 되는 것은 컬럼. 이게 저희 데이터 설계의 일관된 기준입니다."

**[5:00] 슬라이드 9~10 — 아키텍처·4원칙 (120초)**
"Vue 3 프론트, FastAPI 백엔드, PostgreSQL(Supabase). 네 원칙을 파일 단위로 말씀드리면 —
- **Interface First**: `services/agents/base.py`에 추상 클래스가 있고 오케스트레이터는 그 인터페이스만 압니다. Mock 구현체를 LLM 구현체로 갈아끼워도 라우터·스키마·프론트가 안 바뀝니다.
- **Structured Data**: 방금 말씀드린 jsonb / 컬럼 분리 기준입니다.
- **Asynchronous**: 에이전트 실행은 `POST /agent-runs`가 **202**로 받고 폴링합니다. **폴링 주기를 프론트가 정하지 않고 서버가 `pollIntervalMs: 2500`으로 내려줍니다.** 실제 LLM이 붙어 응답이 느려지면 서버가 주기를 바꾸면 되고, 프론트는 손댈 게 없습니다.
- **Security & Config Isolation**: 환경 의존 값을 `core/config.py` 한 곳에서만 읽습니다. AI provider·모델·프롬프트 버전·`egress_allowed`를 `ai_configs` 테이블로 뺐고, **API 키는 이 테이블에 넣지 않습니다 — 환경변수입니다.** 기본이 온프레미스이고, 외부로 나가려면 설정을 명시적으로 켜야 합니다."

**[8:00] 슬라이드 12 — API (60초)**
"엔드포인트 15개입니다. 설계 판단 세 가지만 말씀드리면 —
첫째, **에러 응답을 단일 포맷으로 강제했습니다.** FastAPI 기본 `{detail}`이 아니라 `{code, message, fieldErrors}` 입니다. 코드 23종을 문서에 다 적었고, 프론트는 `code`만 보고 분기합니다. 메시지 문구가 바뀌어도 프론트가 안 깨집니다.
둘째, **403과 409를 분리했습니다.** 남의 요청을 보려 하면 `403 FORBIDDEN_NOT_OWNER`, 엔지니어가 승인하려 하면 `403 FORBIDDEN_ROLE`. 반면 이미 결정된 걸 또 결정하려 하면 `409 ALREADY_DECIDED`. **'권한이 없다'와 '지금 상태에서는 안 된다'는 다른 문제**라서 코드를 갈랐습니다.
